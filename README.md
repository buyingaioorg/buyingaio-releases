# BuyingAIO

Manage retailer orders, track shipments and payouts, and reconcile your purchases
in one desktop app.

## Downloads

[View downloads and release notes](https://github.com/buyingaioorg/buyingaio-releases/releases)

Choose the download that matches your computer:

| Computer | Download |
| --- | --- |
| Mac with Apple Silicon (M-series chip) | `arm64.dmg` |
| Mac with an Intel processor | `x64.dmg` |
| Windows PC (64-bit) | `.exe` |
| Linux PC (64-bit Intel/AMD) | `x86_64.AppImage` |
| Linux device (64-bit ARM) | `arm64.AppImage` |

Mac ZIP downloads are also available. Check each release's notes for availability
and installation requirements. Preview releases are labelled **Pre-release**.

## Updating without removing your current Mac app

1. Finish any imports, syncs or purchases, save your work, and quit BuyingAIO.
2. Download the ZIP for your Mac and extract it in Downloads.
3. Rename the extracted app to `BuyingAIO New.app`, then move it to Applications.
   Keep your existing `BuyingAIO.app` unchanged.
4. Open `BuyingAIO New.app` directly from Applications.

Both copies use your existing BuyingAIO data. **Run only one copy at a time.**
An app filename change does not create a separate account or data folder.

## Your saved data

There is no export or re-import step when updating on the same computer and user
account. BuyingAIO continues to use its existing saved orders, profiles and
settings. Do not uninstall with a cleanup utility or delete BuyingAIO's
application data.

Keeping the old app is not a data backup: both versions share the same files,
and an older app may not support data updated by a newer version. Back up your
data before switching versions. Some services may ask you to sign in again.

Updates currently require a manual download. Follow the signing and installation
notice on the release you choose.
