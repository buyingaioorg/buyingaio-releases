# BuyingAIO releases

This public repository is reserved for BuyingAIO release artifacts and channel metadata, not application source, private configuration, or development history. This initial README does not announce a published release.

## Manual installation channel

Installers in this channel are unsigned or ad-hoc signed, not production-signed/notarized. Operating-system warnings may occur. No seamless automatic updates are promised.

Existing installations may still use the previous release feed. Moving to this channel requires manual installation of an appropriate published installer; changing this repository does not redirect the old feed.

Quit BuyingAIO before replacing the application. Retain the BuyingAIO name, application identifier `com.buyingaio.app`, existing installation identity, and existing local data/encryption identifiers. Do not delete application data, saved orders, or profiles as part of installation. Existing sessions may require signing in again; session restoration is not guaranteed.
